JUMP LAB ELITE

Files:
- index.html: complete app and preview. Open this file in a browser to preview.
- manifest.webmanifest, sw.js, icon-192.png, icon-512.png: installable PWA support.

GitHub Pages:
1. Create a new GitHub repository.
2. Upload all files in this folder to the repository root.
3. Open Settings > Pages.
4. Choose Deploy from a branch, select main and /(root), then Save.
5. Open the published URL. On iPhone Safari, use Share > Add to Home Screen.

Data:
Workout history, jump measurements, and strength logs are stored in localStorage in the current browser. Use History > Export backup before changing devices or browsers.

Ranking:
The first logged set for each exercise establishes that exercise's estimated-max baseline. Later scores measure improvement against that personal baseline. Rank tiers are Wood, Bronze, Silver, Gold, Platinum, Diamond, Champion, Grandmaster, and Olympian. The app does not compare users by age, sex, or bodyweight. Estimates use weight x (1 + reps/30) for sets of 2–10 reps; they are estimates, not a reason to attempt a true one-rep maximum.
